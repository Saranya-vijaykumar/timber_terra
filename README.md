# Timber & Terra — Architectural Outdoor Living Website

A modern, production-ready, multi-page website generated from Stitch Project `10444063813659724051` (**"Timber & Terra Outdoor Website"**) with integrated biophilic design tokens, Tailwind CSS styling, responsive desktop/tablet/mobile layouts, and interactive zero-dependency vanilla JavaScript features.

## 🌲 Pages Overview

1. **Home (`index.html`)**
   - Architectural hero section with high-resolution imagery and direct consultation CTAs.
   - Interactive Before/After project transformation preview toggle.
   - Core performance metrics (18+ years, 450+ custom builds, 25-yr structural integrity guarantee).
   - Architectural timber joinery and sustainable materials showcase.
   - Client reviews and interactive FAQ accordion.

2. **Services (`services.html`)**
   - Filterable discipline catalog (Decks & Platforms, Louvered Pavilions, Pergolas, Outdoor Kitchens, Deck Restoration).
   - **Interactive Cost & Investment Estimator**: Dynamic slider for square footage, material selection, and terrain slope calculation.
   - Technical blueprint specifications and architectural warranties.

3. **Project Gallery (`gallery.html`)**
   - Filterable case studies with live portfolio counters.
   - **Fullscreen Architectural Lightbox**: High-res previews, dimensional specs, timber species metadata, and keyboard navigation (Left/Right arrow keys, ESC).

4. **Pricing Guide (`pricing.html`)**
   - Transparent architectural investment tiers.
   - Hardwood vs. polymer comparison matrices and topography site factors.

5. **About Us (`about.html`)**
   - Heritage story, master carpenter profiles, chain-of-custody timber certifications, and studio philosophy.

6. **Blog & Journal (`blog.html`)**
   - Technical whitepapers, Pacific Northwest winterization guides, and timber maintenance field notes.

7. **Contact & Consultation (`contact.html`)**
   - Commission feasibility request form with real-time validation and instant confirmation response.
   - Direct studio contact info, map anchors, and hours.

## 🚀 Quick Start

Run the zero-dependency local development server:

```bash
# Using npm
npm start

# Or directly with Node.js
node server.js
```

Open your browser to:
[http://localhost:3000](http://localhost:3000)

## 🎨 Design System & Features

- **Palette**: Deep Forest Green (`#183d32`), Dark Pine (`#102b24`), Natural Oak (`#c49a6c`), Soft Sage (`#dce5da`), Warm Ivory (`#f6faf5`).
- **Typography**: Plus Jakarta Sans (Headlines & Display) and Manrope (Body & Technical Specs).
- **Dark/Light Mode**: Full dark mode support with instant switching and `localStorage` persistence.
- **PWA & Mobile**: `manifest.json` included with custom branded favicons and Apple touch icons.
